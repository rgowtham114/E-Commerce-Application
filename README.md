# E-Commerce Store (React + Vite + TypeScript)

A full-featured e-commerce web application rewritten in React, TypeScript, and Vite from the original Django e-commerce application.

## Features Preserved & Implemented

- **Product Catalog & Browsing**:
  - Browse featured and all products across multiple categories: Mobiles, Computers, Beauty & Care, and Flowers.
  - Preserved original product images (Google Pixel 9a, OnePlus 15R, Redmi Note 14 Pro+, Samsung Galaxy M06, iQOO Neo, laptops, skincare, florals).
- **Search & Live Filtering**:
  - Search by product title, description, or category keyword.
  - Category dropdown and quick filter pills with dynamic result counts.
- **Product Details**:
  - Detailed product view with high-resolution image, stock status, pricing, descriptions, and trust guarantees.
- **Shopping Cart**:
  - Add to cart with interactive quantity increment/decrement controls.
  - Automatic subtotal and total calculations in Indian Rupee (₹).
  - Quick removal and proceed to checkout workflow.
- **Wishlist**:
  - Save favorite items for later with one-click toggles and direct transfer to cart.
- **User Authentication**:
  - User sign-up (register) and login flows with validation.
  - Preloaded demo user profile (`gowtham`).
  - Dropdown user menu with profile view and logout.
- **Checkout Flow**:
  - Complete order checkout with delivery address forms (Street, City, State, ZIP code).
  - Multiple payment methods: UPI, Credit/Debit card, Cash on Delivery (COD).
  - Order confirmation screen with unique order IDs and shipping estimations.

## Tech Stack

- **React 18**
- **TypeScript**
- **Vite**
- **Lucide Icons**
- **Pure CSS** with original dark navbar theme and responsive pill styling
